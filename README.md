## Setup

- WM: Aerospace

- Terminal: Kitty

- Editor: Neovim (used LazyVim)

- Bar: SketchyBar

- Shell: zsh

- Fetch: fastfetch

- Theme: Tokyo Night

- Font: JetBrainsMono Nerd Font
